# parqueadero-web

Sistema web para la gestión de parqueaderos, desarrollado con **PHP**, **AJAX**, **MySQL**, **HTML**, **CSS** y **JavaScript**.

## Descripción

**parqueadero-web** es una aplicación web diseñada para administrar y gestionar un parqueadero de manera eficiente. Permite registrar la entrada y salida de vehículos, controlar espacios disponibles, generar reportes y facilitar el cobro automatizado.

## Características principales

- Registro de vehículos (entrada/salida)
- Control de espacios disponibles
- Gestión de usuarios y roles
- Reportes de ingresos y salidas
- Integración con base de datos MySQL
- Interfaz responsiva y amigable

## Tecnologías utilizadas

- **HTML** (57.5%)
- **PHP** (26%)
- **CSS** (12.1%)
- **JavaScript** (4.4%)
- **AJAX** para interacciones rápidas sin recargar la página
- **MySQL** para almacenamiento de datos

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Dants96/parqueadero-web.git
   ```

2. Configura la base de datos MySQL:
   - Crea una base de datos llamada `parqueadero`.
   - Importa el archivo de estructura y datos si está disponible (`database.sql`).

3. Configura la conexión a la base de datos en el archivo PHP correspondiente.

4. Coloca el proyecto en el servidor web (por ejemplo, `htdocs` en XAMPP).

5. Accede a la aplicación desde tu navegador:
   ```
   http://localhost/parqueadero-web
   ```

## Uso

1. Ingresa con tu usuario.
2. Registra la entrada y salida de vehículos.
3. Consulta espacios y reportes desde el panel principal.
